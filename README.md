# SSID: Stepping Stone Intrusion Detection Methods 

### Description

This project contains three aproaches to the problem of *stepping stone intrusion detection*. The first is a modified implementation of **DeepCoFFEA: Improved Flow Correlation Attacks on Tor via Metric Learning and Amplification**. The second is a 'tuned' approach that contains a variety of performance improvements. Then, the ESPRESSO technique is an implementation of the approach described in ESPRESSO: Advanced End-to-End Flow Correlation Attacks on Tor (APNet `24).
